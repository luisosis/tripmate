# TripMate

TripMate es una API RESTFul desarrollada en Java 17 con Spring Boot que permite registrar, consultar, actualizar y eliminar informacion sobre viajes. Ideal para usuarios que desean planificar, organizar o registrar sus experiencias de viaje.


## Stack Tecnologico
- Java 17
- Spring Boot 3.x
- RxJava 3 (Programacion reactiva)
- Srping Data JPA
- Base de datos relacional SQL(MySQL o PostgreSQL)
- Lombok
- MapStruct
- Swagger/OpenAPI(documentacion)
- Maven

### Descripcion del Negocio

TripMate busca facilitar la organizacion y gestion de experiencias de viaje personales o grupales. El sistema permite:
- Registrar viajes con fechas, destinos, gastos y comentarios.
- Consultar detalles historicos o proximos viaje.
- Modificar informacion de viajes existentes.
- Eliminar viajes que ya no se deseen conservar.

Es ideal como sistema de administracion de viajes personales, de empresa o incluso como backend para una app de viajes.
